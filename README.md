# matecusucces

Site static interactiv în română, cu Three.js inclus local.

Pornire locală: `python3 -m http.server 4173 --directory dist`

Deschide http://localhost:4173. Nu este necesară compilarea. Fonturile Google au fallback local sans-serif. Datele nu sunt colectate și nu există conturi sau backend. Cele trei provocări sunt exemple introductive. Designul și referințele sunt documentate în docs/design.md.
